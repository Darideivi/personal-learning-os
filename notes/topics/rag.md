# RAG

## What it is (my words)
Retrieval-Augmented Generation: search a knowledge base first, give what you find to the LLM, then generate the answer.

## Key ideas
- Retrieve → add context → generate. Usually part of a workflow. The model doesn't need to memorize the documents.
