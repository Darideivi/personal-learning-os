# My Knowledge Base

One place so nothing I learn goes to waste. Plain markdown now; my app imports it later.

## The 1-minute rule
Learned something? Put it in `inbox.md` right away: one line, a link, done. Organize later.

## Folders
| Where | What |
|---|---|
| `inbox.md` | Quick capture. Anything, unsorted. |
| `plan.md` | What I'm learning now and next. |
| `topics/` | One file per concept (rag.md, docker.md…). My own explanation. |
| `resources/` | One file per video, course, repo or article, with my notes. |
| `projects/` | Things I built: what, why, problems, what I learned. |
| `journal/` | One file per week: learned / built / questions. |

Each folder has a `_template.md`. Copy it, rename it, fill it in.

## Weekly (15 min, Sunday)
1. Empty the inbox into topics/resources/projects (or delete).
2. Write this week's journal file.
3. Update `status:` on topics I practiced.
4. Glance at `plan.md`.

## Status ladder (for topics)
`not-started` → `learning` → `practicing` → `comfortable` → `confident`
Move up only with evidence: I explained it, used it in a project, or passed a review.

## Frontmatter
Keep the `---` block at the top of each file. It's what the app will import later.
